# Правила для агента

Проєкт: сервіс лояльності для закладів на Syrve (тестове завдання).
План розробки — `docs/PLAN.md`. Він головний: спершу план, потім код.

## Стек

Не додавай бібліотек поза цим списком без явної згоди.

| Частина | Технологія |
|---|---|
| API | Node.js + Express 5, валідація — Joi |
| БД | PostgreSQL + Prisma |
| Фонові задачі | Redis + BullMQ |
| Telegram-бот | grammY |
| Адмін-панель | React + Vite + TypeScript |
| Запуск | Docker Compose |

## Структура

Як у `G:\Projects\contacts-pg`:

```
prisma/          schema.prisma, migrations/
src/
  index.js       точка входу
  server.js      створення Express-застосунку
  routers/       маршрути (+ index.js)
  controllers/   обробники запитів
  services/      бізнес-логіка
  validation/    схеми Joi
  middlewares/   автентифікація, обробка помилок
  db/            клієнт Prisma
  queues/        черги BullMQ
  workers/       обробники задач
  bot/           grammY
  templates/     шаблони повідомлень
  constants/     константи
  utils/         допоміжні функції
docs/            план, OpenAPI, скріншоти
```

Адмін-панель — окремою папкою (`admin/` або `web/`), React + Vite + TypeScript.

## Правила

- **Prisma — лише через міграції.** `prisma migrate dev` із назвою; міграції комітяться. Жодного `db push` і ручних правок схеми в БД.
- **Інтерфейс тільки українською** — повідомлення бота, тексти адмін-панелі, помилки API, повідомлені користувачеві. Коментарі в коді й документація теж українською.
- **Секрети лише в `.env`.** Репозиторій публічний. Нова змінна → одразу в `.env.example` із порожнім значенням. Жодних ключів, токенів, логінів у коді, комітах чи документації.
- **Кожен етап з `docs/PLAN.md` — окремий коміт.** Не змішуй етапи в одному коміті. Повідомлення коміту — українською, у стилі `feat:`, `fix:`, `chore:`, `docs:`.
- **Відхилення від плану записувати в розділ «Зміни плану»** в кінці `docs/PLAN.md`: дата, що змінилось, чому. Без цього запису відхилення не робити.
- `ARCHITECTURE.md`, `AI_LOG.md`, `docs/PLAN.md` не перезаписувати — тільки доповнювати.
