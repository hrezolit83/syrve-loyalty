# Зразки відповідей Syrve Cloud API

Файли в цій папці створює `node scripts/explore.js` (етап 0). Вони потрібні для двох речей:

1. зафіксувати реальну форму відповідей Syrve — на неї спирається мок-клієнт (`SYRVE_MODE=mock`);
2. мати що показати, коли доступу до Syrve немає.

## Правило безпеки

Репозиторій публічний. Скрипт перед записом замінює на `<redacted>`:

- значення полів, чиї імена схожі на секрет (`token`, `apiLogin`, `password`, `secret`, `authorization`);
- будь-яке входження відомих секретів у текст (Syrve повторює `apiLogin` у повідомленні помилки 401).

Id організації, програми й гаманця — не секрети, вони залишаються як є.

## Файли

| Файл | Метод |
|---|---|
| `01-access_token.json` | `POST /api/1/access_token` |
| `02-organizations.json` | `POST /api/1/organizations` |
| `03-loyalty-program.json` | `POST /api/1/loyalty/syrve/program` |

## Стан

Зразків поки немає: виданий `apiLogin` на `https://api-eu.syrve.live` повертає
`401 "Login ... is not authorized"` — так само, як завідомо неіснуючий ключ
(контрольний запит), тож справа не в транспорті, а в самому ключі.
Запит на уточнення надіслано. Скрипт готовий — щойно ключ заработає, зразки
з'являться одним запуском.
